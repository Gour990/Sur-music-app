# SUR — Music App Starter

A responsive, dark-luxury music player interface built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — app structure
- `style.css` — responsive visual design
- `app.js` — navigation, search, local audio import, playback controls and favourites

## Run it
1. Upload these files to your GitHub repository.
2. Open `index.html` with GitHub Pages enabled, or download the repository and open it with a local web server.
3. On the app, tap **Add music** and select audio files stored on your device.

## Current functionality
- Home, Discover, Library, Liked Songs and Profile screens
- Search across imported audio file names
- Import local audio files from your device
- Play/pause, next/previous, seek, volume, shuffle and repeat
- Like/unlike tracks
- Responsive layout for mobile and desktop

## Important notes
- The four featured tracks are visual demo entries, not playable songs.
- This starter plays audio files selected by the user. It does not yet include a cloud music catalogue, user accounts, online streaming backend, or a native Android APK.
- Browser-created audio URLs are temporary. Re-import your audio files after refreshing the page.
- Only import music you own or have permission to play/distribute.
- Google Fonts needs an internet connection; fallback fonts are included.
- For a real Android app, the next stage is packaging this web app with Capacitor and testing on Android devices.
